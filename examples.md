# Примеры использования Ollama Super Agent

## Базовые

```bash
# Интерактивный чат с любой моделью
./ollama-agent.exe --model llama3.1 -i
./ollama-agent.exe --model qwen2:7b -i
./ollama-agent.exe --model deepseek-r1:8b -i
./ollama-agent.exe --model mistral -i
```

## Мощные задачи (агент делает сам)

### 1. Создание игры
```bash
./ollama-agent.exe --model llama3.1 "Создай игру змейка на Python с использованием pygame, сохрани в snake.py и запусти"
```

### 2. Веб-исследование
```bash
./ollama-agent.exe --model qwen2:7b "Найди последние 5 новостей про искусственный интеллект, сделай анализ и сохрани отчет в ai_news.md"
```

### 3. Анализ кода
```bash
./ollama-agent.exe --model deepseek-coder:6.7b "Проанализируй все файлы в папке src, найди баги и предложи улучшения, сохрани отчет в code_review.md"
```

### 4. Автономная разработка
```bash
./ollama-agent.exe --model llama3.1 "Создай полноценное ToDo приложение на C++ с сохранением в JSON, скомпилируй и протестируй его"
```

### 5. Data Science
```bash
./ollama-agent.exe --model llama3.1 "Скачай датасет iris, сделай анализ данных и визуализацию через Python, сохрани графики"
```

### 6. Веб-сервер
```bash
./ollama-agent.exe --model qwen2:7b "Создай REST API сервер на Python Flask для управления заметками с endpoints: GET/POST/DELETE /notes, сохрани в server.py и запусти"
```

### 7. Автоматизация
```bash
./ollama-agent.exe --model mistral "Создай скрипт который каждый час проверяет курс биткоина через web_fetch и сохраняет в bitcoin.log"
```

## Смена модели на лету

В интерактивном режиме:
```
You: /model qwen2:7b
[Model switched to qwen2:7b]

You: Привет, как дела?
```

## Использование инструментов напрямую

Агент сам решает когда использовать инструменты, но ты можешь подсказать:

```
You: Используй web_search чтобы найти информацию про Rust, затем web_fetch чтобы прочитать статью, и сделай отчет
```

## Конфигурация

`agent_config.json`:
```json
{
  "ollama_host": "http://localhost:11434",
  "model": "llama3.1",
  "max_iters": 20,
  "verbose": true,
  "streaming": true
}
```

## Память

Агент помнит между сессиями:
```
You: Запомни что меня зовут Алексей и я люблю Python
Agent: [использует memory_store]

... через день ...

You: Как меня зовут?
Agent: Тебя зовут Алексей...
```

Команды памяти:
- `memory_store` - сохранить
- `memory_recall` - вспомнить

## Советы для максимальной мощности

1. **Используй мощные модели**: `deepseek-r1:8b`, `qwen2:7b`, `llama3.1:8b` дают лучший результат
2. **Давай детальные задачи**: Чем точнее задача, тем лучше результат
3. **Используй max-iters**: Для сложных задач ставь `--max-iters 20` или больше
4. **Включай verbose**: Чтобы видеть как агент думает `--verbose`
5. **Доверяй агенту**: Он сам выберет инструменты и план

## Что делает агента "очень мощным"?

- **ReAct цикл**: Thought -> Action -> Observation
- **12 инструментов**: веб, файлы, код, память, вычисления
- **Автономность**: до 15-20 шагов без участия человека
- **Любая модель**: работает даже с маленькими моделями 3B-7B
- **Проверка**: сам тестирует свой код и исправляет ошибки
- **Память**: помнит контекст между сессиями
